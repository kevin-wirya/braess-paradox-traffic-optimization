# Graph Theory Application in Modeling Braess’s Paradox for Urban Traffic Optimization

This repository contains the Python source code that explores the application of **Graph Theory** in modeling **Braess’s Paradox** — a counterintuitive phenomenon where adding new roads to a traffic network can worsen overall congestion.

The study applies mathematical modeling to urban traffic flow:
- Directed and weighted graphs
- User Equilibrium (UE) vs. System Optimal (SO)
- Price of Anarchy (PoA)
- Dijkstra's algorithm for pathfinding
- Python-based computational simulations
---

## How to Install

1. To run the source code, ensure you have **Python 3.8+** installed. Then, install the required libraries using:

```
pip install -r requirements.txt
```

2. Run the BraessParadox.py in the src folder
```
python BraessParadoxAnalyzer.py
```
